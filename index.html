A FEW THINGS TO KNOW

Before you launch.

Does everyone need to install Astral?

No. Astral is a client-side visual mod. Other players do not need it installed to join the same world. Check each server’s mod rules before using it.

Which Minecraft version is supported?

This download is built for Minecraft Java Edition 1.21.11 with Fabric. It is not a Bedrock mod and is not intended for other Minecraft versions.

Will it affect my FPS?

Visual effects use rendering resources. Start with a few modules and adjust density, detail, and range for your hardware. Sodium is optional and was included in the test setup.

Where do I change settings?

Press Right Shift while in a world. Modules are grouped into Player, World, Skies, Weather, and Interface. Right-click a module card to access its settings.
